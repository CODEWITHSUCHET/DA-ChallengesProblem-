# 🧠 ML Model Comparison for Binary Classification

This project compares multiple machine learning algorithms on a binary classification task using a synthetic dataset. It covers data preprocessing, model training, evaluation, hyperparameter tuning, and performance visualization.

## 📈 Project Overview

Machine learning models behave differently depending on data, tuning, and evaluation methods. This project demonstrates how various popular classifiers perform side-by-side and how GridSearchCV improves them through tuning. A great starting point for beginners in ML or for evaluating baseline performance on new classification tasks.

---

## 🚀 Key Features

- ✅ Preprocessing (Dummy Encoding & Scaling)
- 🔍 Models Included:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - Support Vector Machine (SVM)
  - Gradient Boosting
- 🧪 Evaluation Metrics:
  - Accuracy, Precision, Recall, F1 Score
- 🔧 Hyperparameter tuning with GridSearchCV
- 📊 Matplotlib/Seaborn bar chart comparison of models

---

## 🛠️ Technologies Used

- **Python 3**
- **Pandas**, **NumPy** – Data Handling
- **Scikit-learn** – Machine Learning Models and Evaluation
- **Matplotlib**, **Seaborn** – Data Visualization
